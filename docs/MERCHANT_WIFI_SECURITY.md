# 商家访客 Wi-Fi 安全说明

本说明供平台管理员在录入门店网络前与商家确认。系统只应接入由商家合法提供、与内部业务网络隔离的访客 Wi-Fi。

## 网络选择

- 只录入专门提供给顾客使用的访客 Wi-Fi。
- 不得录入收银/POS、支付终端、监控摄像头、门禁、NAS、服务器、打印机或其他内部设备所在网络。
- 不得录入员工办公网络、公司 VPN、设备管理网络或路由器管理网络。
- 商家应确认其拥有或已获授权管理该网络，并有权向顾客提供连接服务。

## 网络隔离

- 在路由器、无线控制器或防火墙中开启访客隔离、AP isolation 或客户端隔离。
- 优先使用独立 VLAN 和独立子网，将访客网络与收银、监控、NAS、办公及设备管理网段隔离。
- 访客 VLAN 只允许必要的互联网访问；默认禁止访问内部 RFC1918 网段、路由器管理面和其他访客设备。
- 上线前由商家或网络管理员验证隔离规则，不能只依据 SSID 名称判断。

## 密码管理

- 为访客 Wi-Fi 使用独立且足够强的密码，不得复用收银、办公、路由器管理或其他关键系统密码。
- 按商家安全制度定期轮换；人员变动、异常访问、密码公开扩散或疑似泄露时立即轮换。
- 平台管理员只能录入新密码或替换密码，后台不会读取旧密码明文。
- Wi-Fi 密码在数据库中加密保存，不进入应用日志、审计元数据或顾客页面。

## 二维码边界

- 门店二维码只包含随机、不透明的 scene，不包含门店 ID、SSID、BSSID 或 Wi-Fi 密码。
- scene 只用于服务端查找当前有效的门店和连接配置。
- 修改访客 Wi-Fi 密码后，只需在平台后台替换连接配置；现有有效二维码无需重新印刷。
- 二维码停用后，顾客端应无法继续解析连接配置。

## 泄露或异常处理流程

1. 立即在平台停用对应门店服务或当前二维码，阻止继续下发连接配置。
2. 在路由器或无线控制器中修改访客 Wi-Fi 密码，并检查异常客户端和管理日志。
3. 确认访客网络仍与收银、监控、NAS、办公和管理网络隔离；发现串网时先关闭访客网络。
4. 由平台管理员录入新密码并确认旧密码已被替换，不在聊天、工单或截图中传播新密码。
5. 重新启用前完成现场连接、错误密码、Wi-Fi 关闭、重复执行和离页清理测试。
6. 若 scene 或二维码也疑似被滥用，停用旧二维码并生成新二维码；只有这种情况需要重新印刷。
7. 记录事件时间、处理人和非敏感处置结论；不得在事件记录中填写 Wi-Fi 密码或服务器密钥。

## 门店上线确认

- [ ] 这是专用访客 Wi-Fi，不承载收银、监控、NAS、办公或管理设备。
- [ ] 已开启访客隔离或 VLAN，并验证无法访问内部网段。
- [ ] 商家确认有权提供并管理该网络。
- [ ] 访客密码未与任何内部系统或路由器管理密码复用。
- [ ] 已约定密码轮换周期和泄露联系人。
- [ ] 商家理解二维码不包含密码，普通密码轮换无需重印二维码。
